# 📸 Guía para Screenshots del Proyecto

## 🎯 Screenshots Necesarios para README

### 1. **Homepage (homepage.png)**
- Captura de la página principal (`index.html`)
- Mostrar banner, carrusel y navegación
- Resolución recomendada: 1920x1080
- Formato: PNG

### 2. **Productos (products.png)**
- Captura de la página de productos (`productos.html`)
- Mostrar lista de productos y carrito lateral
- Resolución recomendada: 1920x1080
- Formato: PNG

### 3. **Responsive Mobile (mobile.png)**
- Captura en vista móvil (375px width)
- Mostrar adaptabilidad responsive
- Formato: PNG

### 4. **Carrito (cart.png)**
- Captura del carrito con productos
- Mostrar funcionalidad de agregar/quitar
- Formato: PNG

## 🛠️ Herramientas Recomendadas

### **Capturas de Pantalla:**
- **Windows:** Herramienta de Recorte (Win + Shift + S)
- **Chrome DevTools:** Para vistas responsive
- **Lightshot:** Para capturas más profesionales

### **Edición (Opcional):**
- **GIMP:** Gratuito para edición básica
- **Canva:** Para añadir marcos o efectos
- **Paint.NET:** Alternativa liviana

## 📐 Especificaciones Técnicas

### **Resoluciones:**
- **Desktop:** 1920x1080 o 1366x768
- **Tablet:** 768x1024
- **Mobile:** 375x667 (iPhone SE)

### **Formato:**
- **Tipo:** PNG (mejor calidad)
- **Compresión:** Media (balance calidad/tamaño)
- **Tamaño máximo:** 2MB por imagen

## 🎨 Estilo Visual

### **Qué Mostrar:**
- ✅ Interface completa y funcional
- ✅ Datos reales (productos cargados)
- ✅ Estados interactivos (hover, active)
- ✅ Responsive design

### **Qué Evitar:**
- ❌ Páginas en blanco o con errores
- ❌ Lorem ipsum o placeholder text
- ❌ Interfaces rotas o incompletas
- ❌ Calidad baja o pixelada

### Después de Capturar:
